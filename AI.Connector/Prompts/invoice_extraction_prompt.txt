1. Carefully analyze ALL pages of the provided PDF.
2. Perform OCR if needed.
3. Extract ALL invoice information exactly as shown.
4. Normalize and validate the data.
5. Return ONLY valid JSON following the schema below.
6. Do NOT explain anything.
7. Do NOT hallucinate missing data.
8. If a field is not found, return null.

--------------------------------------------------

- Output MUST be valid JSON.
- No comments.

- If multiple VAT rates exist, return them as an array.
- If multiple currencies exist, use the main payment currency.
- If a value is unreadable due to OCR errors, return null.
- Never infer values not explicitly present.

--------------------------------------------------
NORMALIZATION RULES
--------------------------------------------------

1. Number normalization:
   - "1.388.889" → 1388889
   - "1,388,889" → 1388889
   - "1.388.888,88" → 1388888.88
   - Remove all thousand separators.

2. VAT normalization:
   - "8%" → 8
   - "10 %" → 10
   - If multiple VAT levels appear in items, reflect them per item.

3. Currency:
   - Detect currency from symbols (₫, VND, USD, $).
   - Default to VND if clearly Vietnamese invoice and no currency shown.

4. Cross-validation:
   - subtotal + vat_amount should equal total_amount.
   - If mismatch, use the value explicitly labeled as "Tổng cộng thanh toán".

5. Table extraction:
   - Preserve all line items.
   - Do not merge rows.
   - If table columns are misaligned, infer by position consistency.

6. Language priority:
   - If both Vietnamese and English text appear, prioritize Vietnamese labels.

7. Multi-page rule:
   - Extract items from ALL pages.
   - Summary fields usually appear on the last page.
